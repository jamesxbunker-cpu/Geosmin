Phase 1: Cloudflare Tunnel Setup

Installation & Authentication

# Install cloudflared
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt-get update && sudo apt-get install cloudflared

# Authenticate
cloudflared tunnel login
# Create tunnel (or use existing ID)
cloudflared tunnel create geosmin-rp5-server
# Used existing tunnel ID: 0b28e502-53dc-47ff-9a49-0bb216f58bf8

# Get token
TOKEN=$(grep -o '"tunnel_token":"[^"]*"' ~/.cloudflared/0b28e502-53dc-47ff-9a49-0bb216f58bf8.json | cut -d'"' -f4)

Tunnel Configuration

Service override /etc/systemd/system/cloudflared.service.d/override.conf

[Service] ExecStart= ExecStart=/usr/bin/cloudflared --edge-ip-version 4 tunnel run --token-file /etc/cloudflared/token Restart=always RestartSec=5 ExecStartPre=/bin/sleep 10

Phase 2: Network Fixes Applied

ProblemSolutionWhy
IPv6 connectivity failure--edge-ip-version 4Your network doesn't support IPv6
UDP port 7844 blocked--protocol http2ISP blocks QUIC traffic
DNS resolution failure1.1.1.1 and 8.8.8.8 in /etc/resolv.confRouter DNS unreliable

DNS Fix via NetworkManager

WIFI_NAME=$(nmcli -t -f NAME,TYPE con show --active | grep wifi | cut -d: -f1)
sudo nmcli con mod "$WIFI_NAME" ipv4.dns "1.1.1.1 8.8.8.8"
sudo nmcli con mod "$WIFI_NAME" ipv4.ignore-auto-dns yes
sudo nmcli con down "$WIFI_NAME" && sudo nmcli con up "$WIFI_NAME"

Phase 3 & 4: Nginx & Website Files

Nginx Installation & Config

sudo apt update
sudo apt install nginx -y

Config /etc/nginx/sites-available/default

server { listen 8080 default_server; listen [::]:8080 default_server; root /var/www/geosmin/Geosmin; index index.html index.htm; server_name _; location / { try_files $uri $uri/ =404; } }

Initial Clone

sudo git clone https://github.com/jamesxbunker-cpu/Geosmin /var/www/geosmin/Geosmin
sudo chown -R $USER:$USER /var/www/geosmin/Geosmin
sudo chmod -R 755 /var/www/geosmin/Geosmin

Phase 5: Auto-Update System

Final script /usr/local/bin/update-site.sh – full version available in repo. Key fixes:

  • Log file permission check + chown

  • Full path to binaries (/usr/bin/git)

Cron Job
