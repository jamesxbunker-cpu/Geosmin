Phase 1: Driver Implementation

SPI Framing (DS9463 §5.2)

The LIS3MDL uses a bit layout that is different from some of their other sensor families. Double check if you are copying over from an existing project:

bit 0    : RW  (1 = read, 0 = write)
bit 1    : MS  (1 = auto-increment address in multi-byte transactions)
bits 2-7 : AD[5:0]  register address

Command byte = ((reg << 2) & 0xFC) | (auto_inc ? 0x02 : 0) | (read ? 0x01 : 0)

Single Register Write

LIS3MDL_Status_t LIS3MDL_WriteReg(LIS3MDL_Handle_t *dev, uint8_t reg, uint8_t value)
{
    uint8_t tx[2] = {
        (uint8_t)((reg << 2) & 0xFC),   /* R/W=0, MS=0 */
        value
    };
    uint8_t rx[2] = { 0 };

    LIS3MDL_CS_Low(dev);
    HAL_SPI_TransmitReceive(dev->hspi, tx, rx, 2, LIS3MDL_SPI_TIMEOUT);
    return LIS3MDL_CS_High(dev);
}

Multi-Byte Burst Read (Auto-Increment)

uint8_t cmd = (uint8_t)(((reg << 2) & 0xFC)
                        | LIS3MDL_SPI_AUTO_INC
                        | LIS3MDL_SPI_READ);

LIS3MDL_CS_Low(dev);
HAL_SPI_Transmit(dev->hspi, &cmd, 1, LIS3MDL_SPI_TIMEOUT);
HAL_SPI_Receive(dev->hspi, buffer, len, LIS3MDL_SPI_TIMEOUT);
LIS3MDL_CS_High(dev);

Initialization Sequence

1. CS high, 10 ms power-up delay
2. Verify WHO_AM_I == 0x3D
3. CTRL_REG2 = SOFT_RST | REBOOT, then 10 ms delay
4. CTRL_REG1 = TEMP_EN | OM_MP | FAST_ODR
5. CTRL_REG2 = full-scale bits only
6. CTRL_REG3 = MD_CONT         (continuous conversion)
7. CTRL_REG4 = OMZ_MP          (Z-axis performance mode)
8. CTRL_REG5 = BDU             (block data update)

Phase 2: Test Procedure

Float Printing Without newlib

newlib-nano silently drops %f unless linked with -u _printf_float. Instead of adding ~1.5 KB of flash, the harness uses an integer-scaled helper:

static void print_fixed(float v, unsigned scale)
{
    int neg = (v < 0.0f);
    if (neg) v = -v;

    long scaled = (long)(v * (float)scale + 0.5f);
    long whole  = scaled / (long)scale;
    long frac   = scaled % (long)scale;

    unsigned digits = 0;
    unsigned s = scale;
    while (s > 1) { s /= 10; digits++; }

    printf("%s%ld.%0*ld", neg ? "-" : "", whole, (int)digits, frac);
}

Phase 3: Debugging Journey

4.1 · Silent UART

CubeMX had routed USART2_TX to PA14 (SWCLK). The Nucleo-G0B1RE's ST-Link VCP is hardwired to PA2/PA3. Reassigning fixed both the missing output and a "cannot reprogram" issue caused by SWCLK being repurposed.

Lesson On the Nucleo-G0B1RE, USART2 belongs on PA2/PA3 which are also used to program the Nucleo via the Micro-USB. You must program the Nucleo under reset mode if not using external pins (otherwise your MCU will appear 'bricked').

4.2 · Terminal Shows Only Zeros

Two layered problems: the terminal was not properly configured and SPI mode reset. Always double check the baud rate of both devices... Also along the way the SPI mode got reset.

Lesson Always verify pin connections and mappings as a first debugging step.

4.3 · Raw Transmit Works, Sensor Reads Return 0

Repeated CubeMX regenerations kept moving SPI1's pins (PA1/PA6/PB4/PC4 → PA5/PA7/PB1/PC4 and others) while the physical wires stayed put. Every regeneration silently disconnected MISO.

Lesson Freeze the CubeMX pinout, wire to it, and do not regenerate until the driver is stable.

4.4 · SPI Framing Correctness

The original LIS3MDL_ReadRegs used the LIS3DH bit layout (bit 7 = read, bit 6 = auto-inc), which is wrong for the LIS3MDL. Rewritten to match DS9463 §5.2: bit 0 = R/W, bit 1 = MS, bits 2–7 = AD[5:0].

Lesson MSB and LSB can get confusing when working between devices, writing it out helps to see it clearly.

4.5 · Temperature Frozen at 25.00

After the magnetic channels worked, temperature read as exactly 25.00 in every sample of the second loop. Reading back CTRL_REG1 showed 0x7E — TEMP_EN (bit 7) = 0.

Root cause: the read-modify-write pattern in SetODR / SetFastODR / SelfTestEnable will silently clear TEMP_EN if any CTRL_REG1 read returns a value with bit 7 = 0.

Interim Fix Re-call program CTRL_REG1 before the infinite loop to re-enable TEMP_EN.

Interpreting the Output

Magnetic channels

  • Raw counts at ±4 gauss, sensitivity 6842 LSB/gauss
  • Earth's field at test location: |B| ≈ 0.74 gauss
  • X/Y noise ≈ 1%, Z noise ≈ 3% (Z is noisier on this part)
  • Values stable, no saturation, no stuck-at-zero

Temperature channel

  • 8 LSB/°C, 0.125 °C resolution per LSB
  • Offset of +25 °C applied per DS9463 Table 3
  • Reads room temperature (~24.75 °C) as expected
  • Slow to change
